# Carousel Archetypes

Six proven carousel structures. In step 2 of the workflow, match the core idea to an archetype — the archetype dictates the slide arc. Pick the one whose *shape* fits the payoff, not just the topic. Default length 7–8 slides unless the archetype says otherwise.

Selection cheat-sheet:
- Teaching a concept the audience misunderstands → **Framework** or **Myth-bust**
- Actionable "how to do X" → **Steps**
- Quick-win reference the viewer will keep → **List**
- Warning / "stop doing this" → **Mistakes**
- Emotional pull, relatability, trust-building → **Story**

---

## 1. List ("N ta …")
Best for: save-worthy quick references. High save-rate archetype.
Arc:
- S1 Hook: promise the count + the payoff ("5 ta … — 3-chisi eng muhim")
- S2 Stakes: why this list matters now
- S3…N-1: one list item per slide (never two per slide)
- SN CTA: "Qaysi biri sizga yangi edi? Kommentga yozing" or save
Rule: the number in the hook must match the slides. Don't promise 5, deliver 4.

## 2. Steps (bosqichma-bosqich / how-to)
Best for: a process the viewer can follow. Save-rate: high (they return to it).
Arc:
- S1 Hook: the outcome, not the process ("30 daqiqada … — mana qadamlar")
- S2 Stakes / setup: what they need / why most fail
- S3…N-1: Qadam 1, Qadam 2 … one step per slide, in order
- SN CTA: comment keyword → DM with the full guide/template
Rule: steps must be genuinely sequential. If order doesn't matter, use List instead.

## 3. Myth-bust (mif buzish)
Best for: reframing a belief the audience holds. High swipe-through (tension).
Arc:
- S1 Hook: the myth stated as the viewer believes it, then "…adashyapsiz"
- S2 Stakes: what this wrong belief is costing them
- S3–4: why the myth is wrong (the mechanism)
- S5…N-1: the correct model, one piece per slide
- SN CTA: save or keyword → DM
Rule: attack the belief, not the viewer. "Ko'pchilik shunday o'ylaydi" > "Siz xato qilyapsiz".

## 4. Framework (model / tushuntirish)
Best for: teaching a mental model — the explainer strength. Very save-worthy.
Arc:
- S1 Hook: name the framework as a shortcut ("Bu 3 qismli model hammasini oson qiladi")
- S2 Stakes: the confusion it removes
- S3…N-2: one component of the model per slide (build it up)
- SN-1 aha: the whole model assembled in one view
- SN CTA: keyword → DM for a template/cheat-sheet
Pairs well with the `oson-tushuntirish` skill for the analogy on S1–S2.

## 5. Mistakes (xatolar / "shuni qilmang")
Best for: warnings that trigger recognition ("men ham shunday qilardim").
Arc:
- S1 Hook: "Bu … ni o'ldiryapti" — name the silent mistake
- S2 Stakes: the cost of the mistakes
- S3…N-1: Xato #1, #2, #3 … one per slide, each with the fix in one line
- SN CTA: keyword → DM, or "Qaysi xatoni qilgansiz? Kommentga"
Rule: each mistake slide should sting a little (recognition) but offer the fix immediately.

## 6. Story (before → after / case)
Best for: trust and emotion; client results; personal journey.
Arc:
- S1 Hook: the "after" or the turning point ("6 oyda … — qanday")
- S2 Before: the starting pain (relatable)
- S3…N-2: the turning points / what changed, in sequence
- SN-1: the after / result (honest, no inflated numbers)
- SN CTA: "Sizga ham shunday kerakmi? Kommentga 'X'"
Rule: honesty is load-bearing. Real results only; a fake case study destroys trust faster than any other archetype.

---

## Anti-patterns (avoid in every archetype)
- **Title-slide cover.** S1 that just labels the topic. Always a hook.
- **Two ideas on one slide.** Split it.
- **Wall of text.** ≤3 short lines per slide. If it doesn't fit, it's two slides.
- **Dead last slide.** "Rahmat!" with no action. The last slide always converts (DM keyword or SAVE).
- **Closed loops mid-carousel.** Body slides that resolve fully give no reason to swipe. Leave a thread pulling forward.
- **Fabricated numbers.** No invented "%". Reframe to an honest claim.
